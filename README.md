A complete **3-Tier Java application delivery platform** built on AWS EC2 with an automated CI/CD pipeline.

### 🛠️ What I Implemented

* Built a Java-based 3-tier application.
* Configured Jenkins CI/CD automation.
* Integrated Maven build and JUnit testing.
* Integrated SonarQube for code-quality analysis.
* Containerized the backend using Docker.
* Configured Nexus as a private Docker registry.
* Pushed Docker images into Nexus.
* Deployed the application on Kubernetes/K3s.
* Configured Traefik for application traffic.
* Verified deployments using Kubernetes commands and Jenkins.
* Monitored Jenkins, Docker, Kubernetes/K3s and AWS infrastructure.

### 🧯 Real Troubleshooting

Worked through real infrastructure issues including:

`ErrImagePull` • `containerd` • `k3s` • `Traefik` • `Nexus` • `Jenkins` • `SSH` • `Security Groups` • `EC2 IP changes` • `Linux disk management`
