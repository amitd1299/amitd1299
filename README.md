## 🔥 Featured Projects

### 1. 🔐 3-Tier Java CI/CD Pipeline — Jenkins, SonarQube & Nexus

`Java` `Spring Boot` `Maven` `Jenkins` `SonarQube` `Nexus` `Docker` `Kubernetes` `AWS EC2`

A hands-on **3-Tier Java application DevOps project** implementing an automated CI/CD pipeline using Jenkins, SonarQube, Nexus, Docker, and Kubernetes.

The project covers the complete workflow from source-code checkout and automated testing to code-quality analysis, Docker image creation, Nexus image storage, Kubernetes deployment, and deployment verification.

**🔄 CI/CD Flow**

```text
GitHub
   ↓
Jenkins
   ↓
Maven Build & Test
   ↓
SonarQube Analysis
   ↓
Docker Image Build
   ↓
Nexus Docker Registry
   ↓
Kubernetes / K3s Deployment
   ↓
Deployment Verification
```

**What I Implemented**

* Set up a Java-based Maven application with unit tests.
* Configured Jenkins for automated CI/CD.
* Integrated Jenkins with SonarQube for code-quality analysis.
* Configured Nexus as a private Docker Registry.
* Built and tagged Docker images for the backend application.
* Pushed Docker images to Nexus.
* Deployed the application on Kubernetes/K3s.
* Configured Jenkins to perform deployment verification.
* Worked with AWS EC2 and Ubuntu Linux environments.
* Configured required networking, credentials, tools, and service integrations.

**🔧 Troubleshooting Experience**

* Jenkins plugin and tool configuration
* Jenkins workspace and permission issues
* Docker image build and tagging issues
* Nexus Docker Registry authentication and connectivity
* Kubernetes `ErrImagePull` / image availability issues
* K3s and containerd image handling
* Kubernetes pod and deployment troubleshooting
* EC2 networking and Security Group configuration
* Service connectivity and deployment verification
